# Tauscreen

TauScreen

TauScreen é um gravador de tela para Windows desenvolvido para capturar vídeo da tela e áudio de forma simples e prática.

Ele pode ser usado para gravar:

tutoriais;
aulas;
apresentações;
gameplays;
demonstrações de programas;
chamadas e reuniões;
erros e problemas para suporte técnico.

Durante a gravação, o TauScreen utiliza uma janela compacta para permitir o controle sem ocupar muito espaço na tela.

Como instalar

O TauScreen não precisa de uma instalação tradicional.

Baixe o arquivo .zip.
Extraia todo o conteúdo para uma pasta.
Abra a pasta extraída.
Execute:
INICIAR_TAUSCREEN.bat

Na primeira execução, o programa poderá baixar e preparar automaticamente os componentes necessários para a gravação.

Depois disso, o TauScreen será aberto normalmente.

Importante

Não execute o programa diretamente de dentro do arquivo .zip.

Sempre extraia todos os arquivos antes de abrir o TauScreen.

Também não é recomendado mover apenas o TauScreen.exe para outra pasta, pois o programa pode depender dos demais arquivos que acompanham a distribuição.

Requisitos
Windows 64 bits;
espaço livre para armazenar as gravações;
conexão com a internet na primeira execução, quando necessária para preparar os componentes de gravação.
