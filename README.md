# TauScreen

TauScreen é um gravador de tela para Windows desenvolvido com foco em simplicidade, praticidade e controle durante a gravação.

## Funcionalidades

* Gravação da tela.
* Captura de áudio do computador.
* Captura de microfone.
* Gravação de webcam.
* Preview da webcam antes e durante a gravação.
* Rotação da webcam em:

  * 0°
  * 90°
  * 180°
  * 270°
* Espelhamento da webcam.
* Mini janela flutuante da webcam.
* Possibilidade de minimizar a webcam para a barra de tarefas.
* Barra compacta de controle durante a gravação.
* Pausar e continuar gravação.
* Captura de print de uma área selecionada da tela.
* Salvamento automático de screenshots com data e hora.
* Quadro de anotações.
* Desenho livre sobre a tela durante a gravação.
* Borracha por traço segurando `Ctrl`.
* `Ctrl + Z` para desfazer o último traço.
* `Delete` para limpar os desenhos.
* Atalho `Ctrl + Shift + D` para sair do modo de desenho livre.
* Histórico de gravações e capturas.
* Preview de vídeos e imagens dentro do Histórico.
* Seleção múltipla no Histórico.
* Selecionar tudo.
* Remover itens apenas do Histórico.
* Excluir arquivos diretamente pelo Histórico.
* Área de arquivos temporários.
* Recuperação de gravações temporárias.
* Exclusão de arquivos temporários.
* Preview de temporários quando disponível.
* Pergunta para manter ou excluir temporários ao cancelar o salvamento.
* Nomes automáticos organizados para vídeos e capturas.
* Integração com FFmpeg para processamento das gravações.

## Exemplos de uso

O TauScreen pode ser usado para:

* tutoriais;
* aulas;
* apresentações;
* gameplays;
* demonstrações de programas;
* gravação de bugs;
* suporte técnico;
* criação de conteúdo;
* gravações com webcam e microfone.

## Como instalar

O TauScreen não precisa de uma instalação tradicional.

### 1. Baixe o programa

Baixe o arquivo `.zip` da versão mais recente.

### 2. Extraia o ZIP

Extraia todo o conteúdo para uma pasta no computador.

Não execute o programa diretamente de dentro do arquivo `.zip`.

### 3. Inicie o TauScreen

Abra a pasta extraída e execute:

```text
INICIAR_TAUSCREEN.bat
```

Na primeira execução, o TauScreen poderá preparar automaticamente os componentes necessários para gravação.

Uma conexão com a internet pode ser necessária nessa primeira configuração.

## Requisitos

* Windows 64 bits;
* espaço livre para armazenar gravações;
* microfone, caso queira gravar sua voz;
* webcam, caso queira gravar câmera;
* conexão com a internet durante a configuração inicial, quando necessária.

## Importante

Mantenha todos os arquivos da pasta do TauScreen juntos.

Não mova apenas o `TauScreen.exe`, pois o programa pode depender de outros arquivos presentes na mesma pasta.

Para criar um acesso rápido, prefira criar um atalho.
